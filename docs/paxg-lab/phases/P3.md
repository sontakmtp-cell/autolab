# Giai đoạn P3 — Huấn luyện Thủ công và Kho Adapter

## 1. Nhiệm vụ
- Xây dựng vòng huấn luyện LoRA thủ công (`Trainer`), hàm loss kết hợp, cơ chế dừng sớm (early stopping) và lưu checkpoint tốt nhất.
- Hỗ trợ toàn bộ dải tham số thủ công: rank, alpha, dropout, learning rate, batch size, gradient accumulation, context, history length.
- Xây dựng kho lưu trữ adapter an toàn, ghi nguyên tử (`temp_dir` -> verify SHA-256 -> rename), lưu manifest.
- Kiểm tra tính tương thích nghiêm ngặt khi nạp adapter: timeframe, horizon, context, feature set, base revision.

## 2. Tiêu chí Nghiệm thu
- Quá trình học thật trên cả 2 khung 1h và 4h thành công trên RTX 5060 Ti.
- Ngắt tiến trình giữa lúc lưu không làm hỏng adapter cũ.
- Từ chối nạp nếu sai mã băm, sai horizon hoặc thiếu tệp cấu hình.
- Chuỗi chuyển đổi base -> Adapter A -> Adapter B -> base không để sót trọng số.
- Nhận diện chính xác và cảnh báo dữ liệu đánh giá bị trùng với dữ liệu huấn luyện.

## 3. Lệnh thực hiện
